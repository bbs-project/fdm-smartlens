## 소개

FDM SmartLens 는 인공지능 기반 넙치 질병 진단 앱입니다. 카메라를 통해 어류를 촬영하면 실시간으로 질병을 분석하고 진단 결과를 제공합니다.

### 주요 기능

- 📷 **실시간 진단**: 카메라로 촬영하면 즉시 질병 분석
- 📊 **통계 대시보드**: 진단 기록 기반 통계 제공
- 💾 **기록 관리**: 자동 저장된 진단 이력 조회
- 🌍 **다국어 지원**: 한국어 및 영어 지원

## 시작하기

### 시스템 요구사항

**Android:**
- Android 8.0 (API 26) 이상
- 카메라 권한 필요
- 최소 2GB RAM

**iOS:**
- iOS 13.0 이상
- 카메라 권한 필요
- iPhone 8 이상 권장

**React Native (Expo):**
- Expo Go 앱 설치
- iOS 13.0+ 또는 Android 8.0+

### 설치 방법

#### Android (APK 직접 설치)
1. `app-debug.apk` 파일 다운로드
2. 설정 → 보안 → '알 수 없는 소스' 허용
3. APK 파일 실행하여 설치

#### iOS (TestFlight)
1. TestFlight 앱 설치
2. 초대 링크를 통해 앱 설치

#### React Native (Expo Go)
1. Expo Go 앱 설치 (App Store / Google Play)
2. Expo 개발 서버 실행: `yarn start`
3. QR 코드 스캔하여 실행

## 사용 방법

### 1. 진단 시작

1. 앱을 실행하고 '진단' 탭 선택
2. 카메라가 자동으로 활성화됨
3. 넙치를 카메라에 맞추세요
4. 자동으로 감지 및 분석 시작

### 2. 결과 확인

- **정상**: 녹색 배지 표시
- **질병 감지**: 주황색/빨간색 배지 표시
- **신뢰도**: 80% 이상이면 신뢰할 수 있는 결과
- **증상**: 감지된 증상 목록 표시

### 3. 기록 조회

1. 하단 탭에서 '기록' 선택
2. 과거 진단 목록 확인
3. 항목 클릭 시 상세 정보 조회
4. 길게 눌러서 삭제 가능

### 4. 통계 확인

1. 하단 탭에서 '통계' 선택
2. 총 진단 횟수, 평균 신뢰도 확인
3. 질병별 분포 차트 확인
4. 진단 가이드 참고

## 질병 정보

### 감지 가능한 질병

| 질병명 | 주요 증상 | 주의사항 |
|--------|-----------|----------|
| **바이러스성출혈성패혈증** | 출혈, 부종 | 전염성 강함, 격리 필요 |
| **림포시스티스병** | 피부 결절 | 외부 기생충 감염 |
| **여윔병** | 수영 이상, 폐사 | 수온 변화 주의 |
| **스쿠티카병** | 점액 분비, 호흡곤란 | 고밀도 양식 주의 |
| **연쇄구균증** | 안구 돌출, 출혈 | 수온 25°C 이상 주의 |
| **비브리오병** | 피부 궤양, 출혈 | 오염된 사료 주의 |
| **에드워드병** | 복부 팽만, 궤양 | 저산소 상태 주의 |

### 증상 설명

- **Bleeding (출혈)**: 피부 또는 지느러미에서 출혈 관찰
- **Corrosion (부식)**: 피부 또는 비늘 손상
- **Tumor (종양)**: 비정상적인 덩어리 형성
- **Ulcer (궤양)**: 피부 조직 손상 및 괴사
- **EyesSymptom (눈 증상)**: 안구 돌출, 혼탁 등

## 자주 묻는 질문

### Q. 진단 신뢰도가 낮을 때는 어떻게 하나요?

A. 다음 방법을 시도하세요:
- 조명을 밝게 하세요
- 카메라 초점을 맞추세요
- 물체를 가까이 대세요
- 여러 번 촬영하세요

### Q. 오프라인에서도 사용 가능한가요?

A. 네, 모델이 다운로드되면 오프라인에서도 진단 가능합니다. 단, 기록 동기화는 온라인 환경이 필요합니다.

### Q. 진단 기록은 얼마나 저장되나요?

A. 최대 100 개까지 저장됩니다. 오래된 기록부터 자동 삭제됩니다.

### Q. 다른 어종도 진단 가능한가요?

A. 현재는 넙치에 최적화되어 있습니다. 다른 어종은 정확도가 낮을 수 있습니다.

### Q. 앱이 자주 꺼져요

A. 다음을 확인하세요:
- 저장 공간 확보
- 다른 앱 종료
- 앱 재설치
- 기기 재시작

## 문제 해결

### 카메라가 작동하지 않음

1. 설정 → 앱 → FDM SmartLens → 권한 → 카메라 허용
2. 앱 재시작
3. 기기 재시작

### 진단 결과가 표시되지 않음

1. 인터넷 연결 확인
2. 모델 파일 확인 (최초 실행 시 다운로드 필요)
3. 앱 캐시 삭제
4. 앱 재설치

### 앱이 느려짐

1. 사용하지 않는 앱 종료
2. 저장 공간 확보
3. GPU 모드 사용 (설정에서)
4. 기기 재시작

### 기록이 동기화되지 않음

1. 인터넷 연결 확인
2. 로그인 상태 확인
3. 수동 동기화 시도 (기록 화면에서下拉)
4. 앱 업데이트 확인
